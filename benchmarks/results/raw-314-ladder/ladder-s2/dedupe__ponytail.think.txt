The simplest solution:
```python
def remove_duplicate_emails(emails):
    return list(dict.fromkeys(emails))
```

For a list of user objects with an email field:
```python
def remove_duplicate_users(users):
    seen = set()
    result = []
    for user in users:
        if user['email'] not in seen:
            seen.add(user['email'])
            result.append(user)
    return result
```
