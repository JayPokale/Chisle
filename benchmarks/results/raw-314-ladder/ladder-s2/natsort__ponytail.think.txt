The key insight is that we need a custom sort key that extracts numbers and strings separately. The simplest approach without external dependencies is to use a regex-based key function.

Here's the minimal solution:

```python
import re

files = ['file1', 'file10', 'file2', 'file20', 'file3']
files.sort(key=lambda x: [int(c) if c.isdigit() else c for c in re.split(r'(\d+)', x)])
```

Or even simpler with a helper:

```python
import re

def natural_sort_key(s):
    return [int(text) if text.isdigit() else text for text in re.split(r'(\d+)', s)]

files = ['file1', 'file10', 'file2', 'file20', 'file3']
files.sort(key=natural_sort_key)
```
