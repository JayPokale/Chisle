The laziest is probably just:
```python
from itertools import groupby

orders = [
    {"customer_id": 1, "amount": 50},
    {"customer_id": 2, "amount": 100},
    {"customer_id": 1, "amount": 75},
]

totals = {}
for order in orders:
    customer_id = order["customer_id"]
    totals[customer_id] = totals.get(customer_id, 0) + order["amount"]

print(totals)  # {1: 125, 2: 100}
```
