Actually, simplest: use `re` module to extract numeric parts and sort by that key.

```python
import re

files = ["file2", "file10", "file1", "file20", "file3"]

def natural_sort_key(filename):
    return [int(text) if text.isdigit() else text.lower() for text in re.split(r'(\d+)', filename)]

sorted_files = sorted(files, key=natural_sort_key)
print(sorted_files)
```

This splits on digit sequences and converts digit parts to ints for numeric comparison.
