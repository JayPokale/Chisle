A simple, working solution using stdlib is to write a key function that extracts numbers and sorts naturally. This is the lazy solution - no dependency, works with stdlib.

Let me provide code in Python since that's most common, but I can show alternatives.

```python
import re

files = ['file1', 'file2', 'file10', 'file20', 'file3']

def natural_sort_key(filename):
    return [int(text) if text.isdigit() else text.lower() 
            for text in re.split(r'(\d+)', filename)]

sorted_files = sorted(files, key=natural_sort_key)
print(sorted_files)
# Output: ['file1', 'file2', 'file3', 'file10', 'file20']
```

This is the minimal stdlib solution. No dependencies, works, handles the case.
