A simple approach is to use a set to track seen emails, and iterate through the list once, keeping items whose emails haven't been seen before.

Let me write a clean Python solution:

```python
def remove_duplicate_emails(users):
    seen = set()
    result = []
    for user in users:
        if user['email'] not in seen:
            seen.add(user['email'])
            result.append(user)
    return result
```
