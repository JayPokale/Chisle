The stdlib approach is good here. I can use a regex-based key function that splits filenames into numeric and non-numeric parts.

Here's a simple approach:

```python
import re

files = ['file10', 'file2', 'file1', 'file20', 'file3']

def natural_sort_key(filename):
    return [int(text) if text.isdigit() else text.lower() 
            for text in re.split(r'(\d+)', filename)]

sorted_files = sorted(files, key=natural_sort_key)
print(sorted_files)
```

This splits by digits, converts digit groups to ints for numeric comparison, and keeps text as-is.

Output would be: ['file1', 'file2', 'file3', 'file10', 'file20']
