Let me write minimal Python code:

```python
from collections import defaultdict

orders = [
    {"customer_id": 1, "amount": 50},
    {"customer_id": 2, "amount": 30},
    {"customer_id": 1, "amount": 20},
    {"customer_id": 3, "amount": 100},
    {"customer_id": 2, "amount": 15},
]

totals = defaultdict(float)
for order in orders:
    totals[order["customer_id"]] += order["amount"]

for customer_id, total in sorted(totals.items()):
    print(f"Customer {customer_id}: ${total:.2f}")
```
