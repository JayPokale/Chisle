# Pi harness benchmark — 2026-09-11

Pi `0.85.1`, `openai-codex/gpt-5.5`, default six-task suite. Each output-axis arm ran with identical isolated Pi config, no tools, context files, skills, extensions, themes, or session persistence. Only appended arm prompt differed. Raw Pi JSONL events and normalized cells: [`raw-pi/`](./raw-pi/).

Reproduce:

```bash
HARNESS=pi bash benchmarks/run-live.sh openai-codex/gpt-5.5 benchmarks/results/raw-pi
RAW_DIR=benchmarks/results/raw-pi node benchmarks/aggregate.js
```

## Output axis

| segment | vanilla | caveman | ponytail | Chisle |
|---------|--------:|--------:|---------:|-------:|
| coding billed tokens | 1,413 | 1,227 (87%) | **698 (49%)** | 1,035 (73%) |
| non-coding billed tokens | 749 | 324 (43%) | 567 (76%) | **293 (39%)** |
| all billed tokens | 2,162 | 1,551 (72%) | **1,265 (59%)** | 1,328 (61%) |
| all visible-answer tokens | 2,047 | 1,152 (56%) | 1,000 (49%) | **758 (37%)** |
| all answer lines | 301 | 227 (75%) | 113 (38%) | **110 (37%)** |

Chisle did not win billed tokens: ponytail used 63 fewer. Chisle delivered the smallest visible answers and won non-coding billed tokens. This is one six-task run, not a cross-model claim.

Correctness review: every arm passed debounce, cache, pooling, REST-vs-GraphQL, and regex-backreference. Every arm failed the synthetic auth-boundary task: prompt says `currentTime > expiry` rejects equality, but that predicate cannot reject equality; without source, outputs guessed at units or changed semantics instead of proving a root cause. Result: 5/6 tasks passed for every arm.

## Input axis: marginal savings after Pi truncation

Replay corpus: 8,044 persisted Pi tool results from local sessions. Pi had already capped built-in results at 50KB/2,000 lines before persistence. Chisle replay therefore measures savings on top of Pi's native truncation, not against unbounded command output.

```text
tool_results scanned:        8,044  (40,966,395 chars)
scrubbed/elided outputs:       788  (17,426,594 → 6,212,476 chars)
saved:                    11,214,118 chars (~2,803,530 tokens)
                         = 27.4% of persisted tool output
```

Pi dedup is excluded from replay: persisted source order cannot reconstruct parallel completion order. Runtime dedup only compares against an earlier turn. The default allowlist excluded extension tools (including `subagent`); `CHISLE_COMPRESS_TOOLS` opts named extension tools into both runtime and replay. Private session files are not committed; replay is deterministic against any user's own `~/.pi/agent/sessions` corpus:

```bash
node benchmarks/replay-compress.js pi
```

## Runtime checks

A real isolated Pi run loaded the extension, injected exactly one `chisle-rules` custom message, ran a 300-line `bash` result, and exposed an 8,900-char patched result containing the elision marker to the next model turn ([raw JSONL](./2026-09-11-pi-extension-smoke.jsonl)). An isolated local-package `pi install` / `pi remove` round trip preserved unrelated settings. Ten interleaved offline `pi --list-models` timings measured a 157.3ms median without the extension and 158.8ms with it: +1.5ms median startup time on this machine.
