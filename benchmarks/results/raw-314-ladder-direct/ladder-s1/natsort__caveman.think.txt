Or without external library using regex:
```python
import re
def natural_key(text):
    return [int(c) if c.isdigit() else c for c in re.split(r'(\d+)', text)]

files = ["file10", "file2", "file1"]
sorted_files = sorted(files, key=natural_key)
```
