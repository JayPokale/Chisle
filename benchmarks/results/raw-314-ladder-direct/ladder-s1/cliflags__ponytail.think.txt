Let me show a simple, working example:

```javascript
const args = process.argv.slice(2);
let port = 3000;
let verbose = false;

for (let i = 0; i < args.length; i++) {
  if (args[i] === '--port' && args[i + 1]) {
    port = parseInt(args[i + 1], 10);
    i++;
  } else if (args[i] === '--verbose') {
    verbose = true;
  }
}

console.log('Port:', port);
console.log('Verbose:', verbose);
```

This is minimal, works, and doesn't require dependencies. The ponytail comment would note that if they add many flags, they might want a library, but for 1-2 flags this is perfect.
