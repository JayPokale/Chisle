Using `re` module to extract numbers:

```python
import re

files = ['file10', 'file2', 'file1', 'file20']
files.sort(key=lambda x: [int(c) if c.isdigit() else c for c in re.split(r'(\d+)', x)])
print(files)
```

Or simpler with a library:
