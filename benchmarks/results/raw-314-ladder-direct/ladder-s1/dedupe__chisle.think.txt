The most efficient way is to use a set to track seen emails, iterating once:

```python
def remove_duplicate_emails(users):
    seen = set()
    result = []
    for user in users:
        if user['email'] not in seen:
            seen.add(user['email'])
            result.append(user)
    return result
```

def remove_duplicate_emails(users):
    seen = set()

            seen.add(user['email'])
