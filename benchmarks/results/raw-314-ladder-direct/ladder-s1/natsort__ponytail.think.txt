For Python, the simplest stdlib approach is to use a sort key that extracts numeric and text parts:

```python
import re
files = ["file10", "file2", "file1", "file20", "file3"]
files.sort(key=lambda x: [int(c) if c.isdigit() else c for c in re.split(r'(\d+)', x)])
print(files)
```

Or without regex:
```python
import re

```
