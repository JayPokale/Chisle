The simplest approach: `toLocaleDateString()` with an options object to get "Nov 23, 2026" format.

```javascript
const isoTimestamp = "2026-11-23T14:30:00Z"; // from API
const formatted = new Date(isoTimestamp).toLocaleDateString('en-US', {
  year: 'numeric',
  month: 'short',
  day: 'numeric'
});
// → "Nov 23, 2026"
```
