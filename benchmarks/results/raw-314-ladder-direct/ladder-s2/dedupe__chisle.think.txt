Let me write a Python solution:

```python
def remove_duplicate_emails(users):
    seen = set()
    result = []
    for user in users:
        if user['email'] not in seen:
            seen.add(user['email'])
            result.append(user)
    return result
```

Simple, efficient, maintains order. Alternative with dict.fromkeys() would be less clear for this case since we need to track emails specifically and return user objects.
