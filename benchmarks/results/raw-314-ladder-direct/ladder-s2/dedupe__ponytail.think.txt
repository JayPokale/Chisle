The laziest solution that works:

```python
def remove_duplicate_emails(users):
    seen = set()
    result = []
    for user in users:
        if user['email'] not in seen:
            seen.add(user['email'])
            result.append(user)
    return result
```

Or even lazier using dict.fromkeys:
```python
users = dict.fromkeys(users, None)
```

Let me think about the structure. They said "list of users" and want to remove duplicates by email. The cleanest approach assuming users are dicts with an 'email' key:

```python
def remove_duplicate_emails(users):
    seen = set()
    return [u for u in users if not (u['email'] in seen or seen.add(u['email']))]
```
