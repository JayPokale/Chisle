Here's the solution using JavaScript's built-in Intl API (best practice, no dependencies):

```javascript
const date = new Date("2026-11-23T10:30:00Z");
const localized = new Intl.DateTimeFormat('en-US', {
  year: 'numeric',
  month: 'short',
  day: 'numeric'
}).format(date);
console.log(localized); // "Nov 23, 2026"
```

This uses the native Intl.DateTimeFormat API which is perfect for this use case. Alternative would be date libraries like date-fns or Luxon, but stdlib works fine here.

I could also show a quick one-liner with toLocaleDateString(), though Intl.DateTimeFormat is more explicit:

```javascript
new Date("2026-11-23T10:30:00Z").toLocaleDateString('en-US', {
  year: 'numeric',
  month: 'short',
  day: 'numeric'
})
```
