Let me think about the key tradeoffs:

REST:
- Simpler to build and cache
- Stateless, well-understood patterns
- Over/under-fetching data
- Multiple roundtrips for related data
- Good tooling ecosystem

GraphQL:
- Exact data needed (no over/under-fetching)
- Single request for related data
- Steeper learning curve
- More complex server implementation
- Caching is harder
- Potential for expensive queries

Main tradeoff: REST is simpler and more cacheable; GraphQL is more efficient for clients but requires more server-side complexity.
