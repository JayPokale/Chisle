Let me structure the main tradeoffs briefly:

REST:
- Simple, URL-based, easy to understand
- Over/underfetching (you get what server sends, not what you need)
- Many endpoints to manage
- Good caching built-in (HTTP)

GraphQL:
- Query exactly what you need
- Single endpoint, flexible queries
- Steeper learning curve, N+1 problem if not careful
- Caching harder
