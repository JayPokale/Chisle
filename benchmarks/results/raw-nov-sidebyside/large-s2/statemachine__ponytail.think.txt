```python
from enum import Enum
from typing import Set

class OrderState(Enum):
    CREATED = "created"
    PAID = "paid"
    SHIPPED = "shipped"
    DELIVERED = "delivered"
    CANCELLED = "cancelled"
    REFUNDED = "refunded"

class Order:
    TRANSITIONS =

{
        OrderState.CREATED: {OrderState.PAID, OrderState.CANCELLED},
        OrderState.PAID: {OrderState.SHIPPED, OrderState.REFUNDED, OrderState.CANCELLED},
        OrderState.SHIPPED: {OrderState.DELIVERED, OrderState.REFUNDED},
        OrderState.DELIVERED: set(),
        OrderState.CANCELLED: set(),
        OrderState.REFUNDED: set(),
    }
```

I add `__init__` storing order_id and initial state, a `can_transition_to` helper checking membership in the transitions set, and a `transition_to` method that raises a `ValueError` listing allowed next states (or noting terminal state) when invalid.

A demo function walks the happy path—paid, shipped, delivered—then shows failure on an invalid refund-after-delivery attempt, and also demonstrates cancelling before payment.
