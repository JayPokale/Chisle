Pool holds open DB connections. App borrows connection instead of creating new one each request.

**How it works:**
1. App requests connection from pool
2. Available connection in pool → use immediately
3. No available → create new (if under limit) or wait
4. App returns connection to pool when done
5. Pool keeps connection alive for next use

**Why it helps:**
- Skip handshake overhead. New connection = TCP negotiation + auth + setup. Reused = instant use.
- Save resources. Fewer file descriptors, lower memory footprint.
- Handle load better. Sharing connections across requests = process more requests with same resources.
- Prevent exhaustion. Limit total connections. Protect DB from too many concurrent connections.
