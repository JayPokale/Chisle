Main tradeoffs:

REST:
- Simple, standardized (HTTP methods, URLs)
- Cacheable by default (GET/POST/etc)
- Overfetching (get extra fields you don't need)
- Underfetching (need multiple requests)
- Easy to understand, widely known

GraphQL:
- Request exactly what you need (no over/underfetch)
- Single request for complex data
- Steeper learning curve
- Harder to cache
- More complex server-side (resolver complexity)
- Better for client flexibility
