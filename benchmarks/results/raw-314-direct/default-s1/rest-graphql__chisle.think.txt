REST pros/cons:
- Simple to understand and implement
- HTTP semantics align naturally
- Caching via HTTP (easy)
- Overfetching/underfetching common
- Many endpoints required

GraphQL pros/cons:
- Single endpoint, query what you need
- No overfetching
- Steep learning curve
- Harder to cache (HTTP caching breaks)
- Complexity in backend (resolvers, N+1 queries)
- Real-time subscriptions native
