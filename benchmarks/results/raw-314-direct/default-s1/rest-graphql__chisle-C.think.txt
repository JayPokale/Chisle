Main tradeoffs:
1. REST: simpler, cacheable, standardized. GraphQL: flexible queries, one endpoint, but harder to cache
2. REST: over/under fetching. GraphQL: precise data, but query complexity
3. REST: easier to learn/implement. GraphQL: steeper learning curve
4. REST: simpler monitoring/logging. GraphQL: harder to debug
5. REST: N+1 problem easy to hit. GraphQL: mitigates but needs resolver optimization
